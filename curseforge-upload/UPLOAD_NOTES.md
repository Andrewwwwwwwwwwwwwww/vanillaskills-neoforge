# VanillaSkills — NeoForge edition — CurseForge Upload (1.3.3)

Upload as an ADDITIONAL FILE on the existing Vanilla-Skills mod project (1570558) —
same project as the Fabric jar, different loader tag.

## Mod jar
**File:** `vanillaskills-1.3.3+mc26.2-neoforge.jar`
- Minecraft **26.2**, loader tag **NeoForge** (NOT "Forge" — a classic-Forge client can't load it)
- Requires NeoForge **26.2.0.7-beta or newer**; **no Fabric API** (no dependencies at all)
- Display name suggestion: `VanillaSkills 1.3.3 (NeoForge, MC 26.2)`
- Feature-equal with the Fabric 1.3.3 file (textures bundled, resource-pack auto-push,
  mending toggle, trims). Only difference: no Mod Menu config button (Fabric-only).

## Texture pack
Same `VanillaSkills-TexturePack.zip` as the Fabric edition — one pack serves both loaders
(vanilla resource pack, loader-agnostic). Already on the VSTP project; nothing new to upload.
